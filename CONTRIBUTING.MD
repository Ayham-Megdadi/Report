# Contributing

Thank you for your interest in this reports repository.

## This is a Personal Portfolio Repository

This repository documents **my personal work** in Cybersecurity and Cloud Computing.  
It is not a collaborative project open for general code contributions.

## What I Welcome

| Type | Description |
|------|-------------|
| 🐛 **Typo / Error fixes** | Corrections to report content, formatting, or metadata |
| 🔗 **Broken links** | Report a broken link via an Issue |
| 💡 **Suggestions** | Suggest a report category or format improvement via an Issue |
| ⚠️ **Sensitive content** | Flag any inadvertently exposed sensitive information privately |

## What I Do NOT Accept

- Pull requests adding reports you did not author
- Additions that target real production systems or organizations
- Unauthorized reproduction of copyrighted CTF challenge content
- Any content that facilitates illegal activity

## How to Open an Issue

1. Go to **Issues → New Issue**
2. Use a clear title: `[Suggestion]`, `[Error]`, or `[Security]`
3. Describe the issue clearly

## Formatting Standards for Reports

If you are forking this repo as a template for your own portfolio:

- Use PDF for final reports (preserves formatting)
- Follow NIST SP 800-115 structure for pentest reports
- Include: Executive Summary · Scope · Methodology · Findings · Remediation
- Severity ratings: Critical · High · Medium · Low · Informational
