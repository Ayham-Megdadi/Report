# Security Policy

## Purpose of This Repository

This repository contains **technical security reports** produced in authorized, academic, and controlled environments. No content in this repository represents or enables attacks against real production systems.

## Responsible Disclosure

If you discover that any report in this repository inadvertently contains:
- Real credentials or API keys
- Personally identifiable information (PII) of real individuals
- Sensitive infrastructure details of non-fictional systems

**Do NOT open a public GitHub issue.**  
Contact privately so it can be removed promptly.

## Scope of All Reports

Every report in this repository was produced under one or more of the following conditions:

| Condition | Examples |
|-----------|---------|
| ✅ Academic lab environment | University coursework, controlled VMs |
| ✅ Intentionally vulnerable systems | CTF machines, HackTheBox, TryHackMe |
| ✅ Authorized penetration testing | Written permission obtained before testing |
| ✅ Personal/owned systems | Self-hosted labs |

## What This Repository Is NOT

- ❌ A toolkit for unauthorized attacks
- ❌ A collection of exploits for real production systems
- ❌ A guide to attack real organizations

## Legal Notice

All techniques documented in these reports are for **educational purposes only**.  
Reproducing these attacks against systems you do not own or have explicit permission to test is **illegal** under computer crime laws in most jurisdictions.
